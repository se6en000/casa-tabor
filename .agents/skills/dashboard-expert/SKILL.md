# Goal
To architect intuitive, highly readable dashboards and landing pages tailored specifically for managing schedules, to-do lists, and school activities on large touch displays.

# Instructions
*   **Glanceable Architecture:** Design dashboard layouts where upcoming events, active chores, and school deadlines are immediately visible without scrolling.
*   **Widget Modularity:** Structure the UI using modular cards or widgets that can scale dynamically from mobile screens to large kiosk displays.
*   **Landing Page Conversion:** Wireframe landing pages that highlight the emotional relief of streamlined household coordination, using clear, touch-friendly calls to action (CTAs).
*   **Information Hierarchy:** Apply strict typographic scales and whitespace to separate distinct schedules without causing visual clutter.

# Constraints
*   Do not rely on hover states or tooltips for secondary information; all critical data must be visible or accessible via a single tap.
*   Do not violate the 3-click navigation rule when moving from the main dashboard to a detailed view.
*   Do not write backend implementation code; output layout structures, widget specifications, and wireframe descriptions.
